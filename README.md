#Blockchain-Based Digital Land and House Verification System

An academic software project that combines blockchain technology, digital signing, role-based access control, traceability, and verification of land and property transactions.

## Overview

The Digital Land and House Verification System is a prototype developed to address challenges associated with land and property verification, including fraudulent transactions, unauthorized changes, and limited transparency in transaction records.

The system provides a digital platform where landowners and authorised officers can manage and verify property-related transactions through a structured approval workflow. Blockchain technology is used to provide an additional layer of transaction integrity and traceability.

The system is designed as an independent academic and software development project and is not an official system of the Ministry of Lands and Natural Resources.

## Key Features

- Digital land and property registration
- Land transfer management
- Role-based access control
- Digital signing and approval workflow
- Blockchain-based transaction recording
- Property and transaction verification
- Multi-level approval workflow
- Public verification functionality
- Audit and transaction traceability
- Email-based invitation and verification functionality
- Administrative management dashboard

## User Roles

The system supports different user roles according to their responsibilities:

- **Landowner** – submits and manages property-related requests.
- **Land Officer** – reviews and processes land transactions.
- **Senior Officer** – performs higher-level review and approval.
- **Final Authority** – provides final authorization where required.
- **Public Verifier** – verifies publicly available property information.
- **System Administrator** – manages users, system configuration, and administrative functions.

## Digital Signing Workflow

The system uses a system-based digital signing process rather than requiring ordinary users to interact directly with cryptocurrency wallets.

The approval process follows:

```text
User selects Approve & Sign
        ↓
System displays signing confirmation
        ↓
User confirms their identity
        ↓
Digital signature is generated
        ↓
Approval is recorded
        ↓
Blockchain transaction is recorded
